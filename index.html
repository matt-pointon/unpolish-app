Presets that feel designed, not filtered

Each theme maps your prototype's surfaces, lines, text and states to its own system — without changing the layout.

Black & White

Neutral surfaces, clear outlines, simplified type. Status keeps its meaning through hatching and dots.

Sketch

Balsamiq-style hand-drawn strokes and restrained hand lettering. Text stays readable; click targets don't move.

Blueprint

Blue surfaces, light linework and technical type, with a faint drafting grid.

Pastel Blocks

Soft, flat color fields. Groups read as blocks, so the talk stays on grouping and hierarchy.

Install

Let your coding agent do the integration

One dependency-free script and a JSON config. The prompt has your agent inspect the repository, follow its conventions, add the config and check everything still works.

  1. Copy the prompt into your coding agent, in the prototype's repository.
  2. Review the change — usually an unpolish/ folder and one script tag.
  3. Open the prototype and press \. Pick a theme, tune it, copy the configuration back.

Installation prompt

          

        

        

          Install by hand instead
          

            

              
Copy the unpolish/ folder into your static assets and load it after your app. data-config resolves relative to the script. Bundled apps can import the file and call window.Unpolish.init({ config }).

              
To remove it, delete the tag and the folder. Unpolish never edits your components, routes or styles.

            

            
<script src="/unpolish/unpolish.js"
        data-config="unpolish.config.json" defer></script>

// unpolish/unpolish.config.json
{
  "version": 1,
  "defaultTheme": "original",
  "exclude": [".brand-logo", "#map"],
  "themes": { "sketch": { "images": "simplified" } }
}

Live theme settings

            
Color, type and lines, corners, shadows, details, and images — original, simplified or placeholder.

          

          

            
Draft vs. project

            
Tweaks preview instantly and stay in your browser as a local draft. Copy configuration hands your agent the JSON to commit.

          

          

            
Made for presenting

            
\ opens the panel, 1–4 pick a theme, 0 restores, Esc closes. Assign direct keys per theme; nothing fires while typing.

          

          

            
Leave things alone

            
Exempt logos, maps or charts with data-unpolish-ignore or an exclude selector.

          

        

      

    


    

      

        
Review links

        
Send the exact fidelity you mean

        
Review link keeps the current route, query and hash, and opens the page in the chosen theme using the saved project preset — never anyone's local edits. Choose whether viewers see the controls before you copy. If your theme has unsaved edits, Unpolish asks you to save them first.

        /plan/lisbon?tab=venues&unpolish=blueprint&unpolish-ui=hidden#schedule
        

          URL parameter reference
          

            

              
unpolish
original, black-white, sketch, blueprint, pastel

              
unpolish-ui
visible or hidden — hidden is a presentation preference; \ still opens the panel

            

            
Precedence: URL, then your local draft, then the project config. Invalid values fall back quietly, and the treatment survives client-side navigation.

          

        

        

          Compatibility and limits
          

            
Unpolish reads each element's rendered styles and restyles roles through one reversible stylesheet. It works with plain HTML, React, Vue, Svelte and most styling systems, including dynamic content, dialogs, menus and tooltips.

            
    
              
  • Canvas and WebGL draw their own pixels, so they keep their look.
    • 
              
  • Cross-origin iframes and closed shadow roots are out of reach. Open shadow roots are themed.
    • 
              
  • Custom components occasionally need a role hint or a small CSS override in the config.
    • 
              
  • Typography swaps can nudge text widths slightly; pick Keep original for pixel-tight layouts.
    • 
              
  • Modern browsers only: Chrome/Edge 111+, Safari 16.4+, Firefox 113+.
