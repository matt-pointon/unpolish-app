Presets that feel designed, not filtered

Each theme maps your prototype's surfaces, lines, text roles and states to its own system. Roughness changes what's appropriate for that theme — never the layout.

Neutral surfaces, clear outlines, simplified type. Status keeps meaning through hatching and dots instead of color.

Install

Let your coding agent do the integration

Unpolish is one dependency-free script plus a JSON config. The prompt asks your agent to inspect your repository, choose the smallest integration that fits its conventions, add the config, and verify that everything still works.

  1. Copy the prompt and paste it into your coding agent in the prototype's repository.
  2. Review the change. Usually a vendored unpolish/ folder and one script tag.
  3. Open the prototype and press \. Pick a theme, tune it, copy the configuration back.

Prefer to do it by hand?

          
One tag, one file

          
Copy the unpolish/ folder into your static assets and load it after your app. Paths in data-config resolve relative to the script.

          
Bundled apps can import it instead: import './vendor/unpolish.js', then window.Unpolish.init({ config }).

          
Removing it is deleting that tag and the folder. Unpolish never edits your components, routes or styles.

        

        
<!-- index.html, after your app's scripts -->
<script src="/unpolish/unpolish.js"
        data-config="unpolish.config.json" defer></script>

// unpolish/unpolish.config.json
{
  "version": 1,
  "defaultTheme": "original",
  "exclude": [".brand-logo", "#map"],
  "shortcuts": { "toggle": "\\", "themes": {} },
  "themes": {
    "sketch": { "roughness": 60, "images": "simplified" }
  }
}

      

    


    

      

        

          
Great defaults. Tune when it matters.

          
The panel opens with themes and one Roughness dial. Everything else waits behind Edit theme.

        

        

          

            
Live theme settings

            
Palette and neutrals, typography, border weight and style, corner radii, shadows, decorative details, and image treatment — original, simplified or placeholder.

          

          

            
Saved per theme

            
Each theme keeps its own adjustments. Reset preset returns that theme to the project's defaults.

          

          

            
Draft vs. project

            
Tweaks preview instantly and persist in your browser as a local draft. Copy configuration hands your agent the JSON and instructions to commit it.

          

          

            
Leave things alone

            
Exempt logos, maps or charts with data-unpolish-ignore or an exclude selector. Canvas, WebGL and cross-origin frames are always left as they are.

          

        

      

    


    

      

        

          
Keyboard

          
Made for presenting

          
Switch fidelity mid-meeting without hunting for controls. Shortcuts never fire while you're typing in a field, and every action also has a pointer and touch equivalent.

          
Assign a direct key to any theme from Shortcuts in the panel. Unpolish shows what's bound, rejects duplicates, and steers you away from keys your browser or OS already own.

Review links

          
Send the exact fidelity you mean

          
Copy review link keeps the current route, your app's own query parameters and hash, and adds namespaced Unpolish parameters.

          
Links apply the saved project preset — never the recipient's local edits — and survive client-side navigation. If your theme has unsaved tweaks a link can't carry, Unpolish asks you to save them first.

          
Hidden controls are a presentation preference, not a lock: \ still opens the panel.

Honest about edges

          
Broad coverage, not magic

          
Unpolish reads each element's rendered styles and restyles roles — surfaces, lines, fills, text, media, states — through one reversible stylesheet. It works with plain HTML, React, Vue, Svelte and most styling systems, including dynamic content, dialogs, menus and tooltips.

        

        
    
          
  • Canvas and WebGL draw their own pixels, so they keep their look.
    • 
          
  • Cross-origin iframes and closed shadow roots are out of reach. Open shadow roots are themed.
    • 
          
  • Custom components occasionally need a role hint or a small CSS override in the config.
    • 
          
  • Typography swaps can nudge text widths slightly; pick Keep original for pixel-tight layouts.
    • 
          
  • Modern browsers only: Chrome/Edge 111+, Safari 16.4+, Firefox 113+.
