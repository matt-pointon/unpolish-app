          Manual installation
          

            

              
Script tag

              
Download unpolish.js into an unpolish/ folder, put unpolish.config.json next to your pages (schema), and add to the <head>:

              
<script src="unpolish/unpolish.js"
  data-config="unpolish.config.json" defer></script>

              
To remove: delete the tag, the folder and the config.

            

            

              
npm package

              
Install the exact version, then start it once in browser code. Importing is safe during server rendering.

              


import { init } from 'unpolish';
init({ configUrl: '/unpolish.config.json' });

              
Put the config in public/. To remove: delete the call and uninstall.
