# Unpolish

**Less polish. Better conversations.**

Unpolish puts a reversible lo-fi theme over a working web prototype — Black & White, Sketch, Blueprint or Pastel Blocks — so stakeholder reviews focus on structure, content and flow while every click, route and form keeps working.

## What's here

| Path | What it is |
| --- | --- |
| [`packages/unpolish/`](packages/unpolish/) | **The npm package** — browser runtime (ESM, CommonJS, script-tag bundle), types, config schema and starter, and the `init`/`remove` installer. [README](packages/unpolish/README.md) |
| [`unpolish/`](unpolish/) | What the website serves for self-hosting: `unpolish.js`, starter config, schema, guide, and the packed preview tarball. Generated by `npm run release` |
| [`releases/`](releases/) | Versioned copies of the self-host files so `unpolish/<version>/` URLs survive rebuilds |
| [`index.html`](index.html) + [`site/`](site/) | Product website with a live demo and the copyable agent installation prompt |
| [`site/demo/`](site/demo/) | The polished prototype used in the website demo |
| [`examples/`](examples/) | Validation apps: plain HTML, React + Tailwind, Vue, Svelte |
| [`tests/`](tests/) | Playwright suite; results and limits in [`docs/VALIDATION.md`](docs/VALIDATION.md) |
| [`docs/ANIMATION.md`](docs/ANIMATION.md) | Motion decisions and review |
| [`vercel.json`](vercel.json) | Static Vercel host: `npm run build:site` → `public/` |

## Try it

```sh
npm install
npm run serve            # http://localhost:4173 — website + demo
```

Open the site, use the demo controls, or press `\` inside the demo prototype for the real panel. `npm run build:site` writes the files Vercel serves into `public/` (gitignored). Production: `https://unpolishdesign.vercel.app`. Install commands on the site are `npx unpolish@latest init`; the copied agent prompt pins `npx unpolish@0.1.0`.

## Install into a prototype

```sh
npx unpolish@latest init --dry-run   # see the plan
npx unpolish@latest init
```

The copied agent prompt pins `npx unpolish@<version>` so a reviewable prototype does not float on `latest`. Where installs come from is set in one place, [`release.config.json`](release.config.json); the website derives every command and the agent prompt from it.

**Script tag** (no Node at runtime): put `unpolish.js` and `unpolish.config.json` next to the pages and add:

```html
<script src="unpolish/unpolish.js"
  data-config="unpolish.config.json" defer></script>
```

Setup, configuration, updates and removal: [`packages/unpolish/README.md`](packages/unpolish/README.md). Publishing, Vercel and rollback: [`docs/RELEASE.md`](docs/RELEASE.md).

## Test

```sh
npm run release          # rebuild the package, unpolish/ files, releases/<version>/ and site/release.js (keeps an existing tarball)
npm run build:site       # static site into public/
npm run check:dist       # confirm a public copy of unpolish/ matches the build
npm test                 # release artifacts, example builds, site build, then Playwright
```

Chromium is used from `/opt/pw-browsers` when present; otherwise run `npx playwright install chromium` first.
